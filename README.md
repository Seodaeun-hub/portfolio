## 주요 프로젝트

### NEWZED | AI 검수·WMS 연계 플랫폼
- FastAPI 기반 검수·관리자 API 및 역할별 접근 권한 구현
- Celery·Redis 기반 비동기 처리와 WMS 후속 작업 연계
- Redis Pub/Sub·SSE를 활용한 상태 전달 및 연결 시 현재 상태 조회
- 비교 실험에서 AI 실행 4회→1회, 상태 확인용 DB 조회 98.2% 감소

### CRYPTOVA | AI 기반 매매 보조 서비스
- 2인 공동 개발: 외부 API 데이터 처리, 모델 비교 및 웹서비스 구현
- 실제·가상 주문 경로 분리와 주문·포지션·실행 이력 관리
- 기존 포지션이 있는 상태에서 순차 재요청 10회의 추가 주문 차단
- 평가 구간별 백테스트를 통한 입력 정보와 매수 제한 조건 검토

### MOJI | 두피·탈모 자가 모니터링 서비스
- 이미지 검수·전처리 및 부위별 분류 모델 학습·평가
- 정수리 3단계·이마 라인 2단계로 분류 체계 구성
- 테스트 정확도: 정수리 85.45%, 이마 라인 86.73%
- 오분류 분석을 통한 촬영·전처리 개선 기준 제안
